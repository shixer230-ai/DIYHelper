# DIYHelper —— DIY 硬件性价比助手


一个帮你从 CPU / 显卡到整机方案，挑出最划算配置的安卓 App。

## 版本

**Beta 1.1.3**（构建号 1.1.3+6）

## 主要功能

- **硬件清单**：手工录入价格 / 型号，本地保存，按品类分栏
- **硬件库**：预置 100+ 主流型号（CPU / 显卡 / 主板 / 内存 / 硬盘 / 电源），含参数与跑分，支持关键词搜索、品牌分组
- **整机方案**：多方案管理、按槽位选配、一键保存到清单、兼容性检测（CPU↔主板插槽、内存代别、电源功率）
- **性价比分析**：按跑分项目（CPU-Z / 3DMark 等）计算性价比并排行，另支持整机功耗排行与自定义项目排行
- **配置单导入导出**：一键导出为文本（系统分享面板），一键粘贴还原整机方案
- **个性化**：主题色、自定义背景（可模糊）、深浅色、昵称、自定义头像
- **液态玻璃 UI**：iOS 26 风格底部导航（真实折射 + 跟手滑动）
